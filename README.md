# Circle — Communities App

Community-discussion app in an interactive phone frame.

**[Live Demo](https://shaisolaris.github.io/rn-circle/)**

## Features

- **Feed** — four seeded communities with All/per-community filters, hot-sorted by live score
- **Voting** — up/down with toggle-off, score math reflected everywhere including thread view
- **Threads** — full post view with nested replies, comment upvotes, inline reply, and add-comment composer
- **Post composer** — FAB-launched sheet with community picker; new posts land at the top of the feed with your upvote

## Structure

Single self-contained page: shared post/comment state driving feed, sorting, and thread rendering. React-Native-style mobile UI in pure HTML/CSS/JS. No frameworks, no build step.
